# BMN Changelog — Liquid Chrome Edition

- Reworked homepage messaging and primary calls to action.
- Added a dedicated creator biography/profile section.
- Added official social links and a working copy-site-link action.
- Added animated liquid-chrome background layers and more optical edge reflections.
- Added a restrained gold/yellow accent alongside blue, violet, cyan and silver.
- Improved dark/light appearance treatment while retaining the theme toggle.
- Expanded command palette navigation for Creator and Official Links.
- Preserved existing work search/filter, project modal, local BMN LIVE editor, glass controls, reduced-motion, low-data, install prompt, notifications, contact form, and floating dock.

Note: BMN LIVE edits remain local to the current browser/device. Cross-device publishing requires a backend.

## Optical refraction enhancement
- Added a hidden, correctly namespaced SVG turbulence/displacement filter inspired by the supplied demo.
- Added progressive enhancement for browsers that support SVG filters in `backdrop-filter`; standard blur/saturation remains the fallback.
- Sharpened specular rims and internal caustic highlights for the transparent liquid-chrome surface.
